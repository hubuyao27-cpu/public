# Edge Cases, Failure Modes & Honest Fallback Rules (`sci-intro-rw-writer`)

Apply these deterministic rules whenever `/input/` materials are incomplete, conflicting, corrupted, or ambiguous. **Never fabricate citations, metadata, metrics, or experimental results to smooth prose.**

| # | Condition Detected | Required Agent Behavior | Output `status` & Required Annotations |
|---|---|---|---|
| 1 | **Empty literature library or zero source files** (`references_catalog` empty, or no own-paper materials) | Do NOT invent references or experimental results. Draft only structure/outline explicitly grounded in `/input/task.md` & `case.json`, or report insufficient evidence honestly. | Set `status: "insufficient_material"` (or `"partial"` if own-paper facts exist). Insert `[待作者确认: GAP-01]` / `[AUTHOR_CONFIRM: GAP-01]` and add actionable items to `author_confirmation_items[]` and `uncertainty[]`. |
| 2 | **Citation key / inline marker has no original text or incomplete metadata** (missing year, author, or venue) | Preserve the citation key rather than guessing missing bibliographic fields. Classify as `verification_status: "unverified_source"` (missing source) or `"partial_metadata"` (missing fields). | Keep missing fields explicitly as `"Unknown"` / `"[待补充]"`; add `[待作者确认: GAP-XX]` inline and a closed-ended question in `author_confirmation_items[]`. |
| 3 | **Cross-source metadata or numeric conflicts** (`CONF-XX`, e.g., `.bib` year `2022` vs PDF `2023`, or draft metric `91.5%` vs table `90.8%`) | Follow precedence (`original_paper_or_pdf > bibtex_or_csl_metadata > own_paper_results_or_tables > own_paper_manuscript_or_methods > structured_notes > narrative_draft`). Disclose ALL conflicts explicitly. | Populate `conflicts[]` with both conflicting values & locators, record the correction in `change_records[]`, and set `needs_author_confirmation: true` when tie/uncertainty remains. |
| 4 | **Target journal / citation format unspecified** (`citation_style == "unspecified"`) | Adopt a clean default matching the input language (`gbt7714` for Chinese, `ieee_numeric` for English/STEM, `apa_author_year` if existing draft uses `(Author, Year)`), and apply it 100% uniformly across prose and bibliography. | Document the adopted default and venue ambiguity in `uncertainty[]` and add a recommended confirmation item (`author_confirmation_items[]`). |
| 5 | **Language switching or bilingual writing** (`language == "bilingual"`, or mixed Chinese/English inputs) | Produce consistent bilingual sections or target-language prose while preserving canonical English technical terms and exact numeric/citation tokens on first occurrence. | Record terminology/language mapping decisions in `change_records[]` and verify numeric parity across both languages. |
| 6 | **Research gap lacks direct cited support** (not directly evidenced by limitations/conflicts in `references_catalog`) | Never pass unsubstantiated speculation off as an established literature fact. Explicitly separate literature-derived gaps from author judgment. | Set `derivation_type: "author_judgment"`, `attribution: "author_judgment"`, insert inline `[作者判断]` / `[AUTHOR_JUDGMENT]`, and add a confirmation item asking the author to supply supporting citations or confirm the judgment. |
| 7 | **Encrypted / corrupt / scanned PDFs or overclaimed contributions** | Record exact PDF read errors (`pdf_encrypted`, `pdf_corrupt`, `scanned_ocr_low_conf`) in `uncertainty[]`. Qualify contributions with exact dataset/condition scope; replace unverified superlatives (`首次彻底解决`, `universally outperforms all`). | If contribution lacks own-paper evidence locator, set `verification_status: "author_confirm_required"` with `[待作者确认: GAP-XX]`. Log removed overclaims in `change_records[]`. |
